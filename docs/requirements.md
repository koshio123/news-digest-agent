# 要件定義

## 目的

エンジニアとしてのロールと興味を設定すると、論文・ニュース・ブログ・SNSなどから関連する最新情報を幅広く集め、重要なものを抽出・要約して届ける。

## 要件

| 論点 | 決定 | 実装 |
|---|---|---|
| 利用者 | 自分専用 | 認証なし。設定は `profile.yaml` と `.env` |
| 実行形態 | 定期バッチ＋オンデマンド | launchd（`scripts/install_launchd.sh`）／ `uv run digest run` |
| 対象期間 | 前回実行から今まで。前回の実行に含まれた記事は除く | 前回の**成功した**実行の終了時刻から。既読は SQLite の `items` で除外 |
| 情報源 | 論文・ニュース・ブログ・SNSなど幅広く | MVP: arXiv＋RSS 12本（HN・Redditを含む）＋Tavily |
| 「重要」の定義 | 実務への応用性・関連度・インパクトで総合的に | 3軸を1〜5で採点し、重み付きで0〜100に換算（重みは `profile.yaml`） |
| 出力先 | Markdown＋Slack | `output/digests/YYYY-MM-DD_HHMM.md`、Slack Bot（記事ごとに投稿） |
| フィードバック | あり | Slackの 👍/👎 リアクション、または `digest feedback` コマンド。次回の採点プロンプトに反映 |

## MVPの範囲外（フェーズ2以降）

- 埋め込みによる意味的な重複排除・事前フィルタ
- 記事本文の取得（現状はRSS要約・アブストラクト・検索スニペットのみで要約する）
- X（Twitter）など、有料APIが必要なSNS
- フィードバックからのプロファイル自動更新
- 評価セット（手でラベル付けした記事）による採点精度の計測
- Web UI
